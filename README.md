# Laporan Warden (PWA)
1. Cipta repo GitHub, upload semua fail (termasuk folder .github).
2. Settings > Pages > Source: **GitHub Actions**.
3. Tab Actions > tunggu "Deploy PWA" siap. Pautan: https://NAMA.github.io/NAMA-REPO/
4. Buka pautan di Chrome Android > menu ⋮ > **Pasang aplikasi / Add to Home screen**.
